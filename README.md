# 🍲 MamaCook

MamaCook est une application web dédiée à la gestion et à la découverte de recettes sénégalaises. Elle permet de consulter les recettes et leurs ingrédients, ainsi que de gérer les recettes après connexion.

## ✨ Fonctionnalités

- Consulter la liste des recettes sénégalaises
- Afficher les détails d’une recette, ses ingrédients et ses étapes de préparation
- Se connecter pour ajouter, modifier ou supprimer des recettes

## 🛠️ Technologies

- HTML, CSS et JavaScript
- PHP
- MySQL avec PDO
- XAMPP pour le développement local

## 🚀 Lancer le projet en local

1. Démarrer Apache et MySQL avec XAMPP.
2. Placer le dossier du projet dans `htdocs`.
3. Créer la base de données et importer le script SQL du projet.
4. Configurer la connexion à la base de données.
5. Ouvrir le projet dans un navigateur à l’adresse `http://localhost/MamaCook`.
